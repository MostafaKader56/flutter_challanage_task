## 🔥 Firebase Integration

This project is already set up to connect to a Firebase project.

- The configuration file `lib/firebase_options.dart` has been generated by the FlutterFire CLI and contains the necessary keys for Android and iOS.

- **Important**: To fully connect to Firebase, you will need the platform-specific configuration files which are not checked into version control for security reasons:
  - For **Android**: Place your `google-services.json` file in the `android/app/` directory.
  - For **iOS**: Open `ios/Runner.xcworkspace` in Xcode and add your `GoogleService-Info.plist` file through the project navigator.

If you wish to connect this app to your own Firebase project, you can reconfigure it using the FlutterFire CLI:

```sh
flutterfire configure
```
